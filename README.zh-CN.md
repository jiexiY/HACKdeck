# HACKdeck

### 找到合适的活动，看清时间安排，为创作留出空间。

[访问 HACKdeck](https://hackdeck-app.vercel.app/) · [English](README.md) · [Español](README.es.md)

HACKdeck 是一个多语言活动发现平台，将黑客松、Build Week 和开发者项目整理成连贯的时间线卡片，帮助参与者在投入时间之前比较机会。

## 主要功能

- 可拖动的时间线和按日期排列的活动卡片。
- 按主办方、地点、远程参与、日期、截止时间、奖金、资格、形式和状态筛选。
- 活动详情及官方或主办方来源链接。
- 英文、简体中文和西班牙文界面。
- 无需注册即可在浏览器中收藏活动。
- 通过 JSON 导出和导入，在不同浏览器或设备间转移收藏。
- 适配桌面和较小屏幕的响应式布局。

## 产品思路

活动目录能告诉人们有哪些机会，但做计划还需要了解申请截止时间、活动是否冲突、能否远程参加，以及自己是否符合资格。HACKdeck 将这些信息集中到直观的时间线中，让比较和筛选更容易。

## 使用方法

打开网站，选择语言并设置筛选条件。浏览时间线、查看活动详情，并在申请前确认主办方的最新信息。将感兴趣的活动加入收藏；更换浏览器时，使用 JSON 备份进行转移。

## 来源与时效性

活动资料根据公司、大学或主办方的官方来源整理。被监测的组织只是发现线索，不会自动成为活动记录。

这不是保证实时更新的信息流。活动日期、资格、奖金和申请规则可能变化，请以原始来源为准。数据验证程序会提示需要维护的记录，包括尚未归档的已结束活动。

## 技术实现

项目使用 React 19、Vite、Tailwind CSS、Radix UI、Lucide 图标和 OGL 视觉效果。

- `src/App.jsx`：时间线、筛选、详情和收藏交互。
- `src/data/events.js`：活动及来源数据。
- `src/data/i18n.js`：界面翻译。
- `scripts/validate-events.mjs`：数据一致性检查。

## 本地运行

需要 Node.js 20 或更新版本及 pnpm。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开 Vite 输出的本地地址。

```bash
pnpm validate:data
pnpm build
pnpm preview
```

数据验证和编译是不同的检查。发布活动数据更新之前，应根据主办方来源处理验证结果。

## 收藏与隐私

收藏通过本地存储保留在访问者的浏览器中，不会上传至账户。清除浏览器存储可能导致收藏丢失。JSON 导出和导入可用于备份与转移，但不是自动跨设备同步。

## 参与贡献

提交活动新增或更正时，请提供官方来源，保留未知信息，检查重复 ID 和网址，并归档已结束的活动。界面修改应保留键盘操作、清晰标签、响应式布局及三种语言支持。
